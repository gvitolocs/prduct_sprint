# Furniture DPP readiness — Prduct sprint

Live: https://demosprint.vercel.app

A Prduct-styled Digital Product Passport assessment. The page keeps the Prduct
header and hero at the top; below it, the assessment is now a cinematic
**product data journey** (`journey/`). The earlier linear 12-question quiz is
preserved unchanged at `/classic.html`.

## Product data journey

Choose a product world — **lounge chair** (furniture), **e-bike battery**
(battery & e-mobility) or **rain jacket** (textiles & apparel) — and the camera
travels through it: Company → Product → Material → Component → Supplier →
Logistics → Factory → Data → Passport → Next life. One situation appears at
each stop; the lifecycle rail along the bottom tracks the journey and, at the
end, rises into the **Product Data Landscape**.

| File | Role |
|---|---|
| `pathfinder/lifecycle.js` | Journey scenario bank (branch wording), adaptive router, landscape assembly — on the Pathfinder capability model |
| `journey/app.js` | Choreography: selector → travel → landscape, persistence, back / rail navigation |
| `journey/stage.js` | Viewport: stills + double-buffered video, seamless still→clip→still swaps |
| `journey/rail.js` | Lifecycle rail with the travelling bead and evidence marks |
| `journey/panel.js` | One situation at a time, entering from the right |
| `journey/landscape.js` | Product Data Landscape: map, facts, breaks, next moves, passport rows |
| `journey/media.js` | Manifest access, AVIF/WebP and AV1/H.264 selection, preloading |
| `journey/manifest.json` | Branch → stage → anchor / transition (generated by `../journey-media/tools/build_web.py`) |
| `journey/media/` | Delivered stills and clips (generated, content-revisioned URLs) |
| `journey/assets-metadata.json` | How every still and clip was made: models, seeds, prompts, settings, licences (copied from `../journey-media/`) |

Scoring is Pathfinder's 13-dimension capability model unchanged; branches only
change wording and examples. Calculator-compatible hints keep the original
timeline band available. Media generation lives in `../journey-media/`.

Checks: `node --test pathfinder/tests/*.test.mjs`. `?motion=reduced` forces the
reduced-motion path (stills cross-fade, no video downloads) for QA.
