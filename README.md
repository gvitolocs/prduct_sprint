# Furniture DPP readiness — Prduct sprint

Live: https://demosprint.vercel.app

A Prduct-styled furniture Digital Product Passport readiness assessment. Questions and scoring come from the Spin-in board (furniture DPP data types, supply-chain reach, commercial intent) plus the same operational bands a DPP calculator uses for the timeline.
